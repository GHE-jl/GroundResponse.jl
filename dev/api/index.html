By topic

Ground model types

  • AbstractGroundModel — the abstract supertype and extension point
  • ILSModel, ICSModel, FLSModel — conductive models
  • MILSModel, MFLSModel — moving (advection) models

Single-borehole g-functions

  • ils — infinite line source
  • ics — infinite cylindrical source
  • fls — finite line source
  • mils — moving infinite line source
  • mfls — moving finite line source

High-level interface

  • ground_response — dispatch over model type and field size

Spatial superposition methods

Presented in order of increasing boundary-condition detail (BC-I → BC-II → BC-III):

  • uniform_flux — BC-I: equal flux on every borehole (Guo et al., 2021)
  • successive_flux — BC-II: iterative equal-mean-temperature solve (Nguyen & Pasquier, 2021)
  • bloc_matrix — BC-II: direct block-matrix solve (Dusseault et al., 2018)
  • segment_response — BC-III: segment (uniform-wall-temperature) solve (Cimmino & Bernier, 2014)
  • segment_response_marching — BC-III: stepwise time-marching alternative to the block matrix (Cimmino, 2018)

The boundary condition is selected on FLSModel through its optional nseg field (nseg > 1 ⇒ BC-III).

Borefield layouts

  • borefield — unified entry point
  • borefield_geometry — pairwise distance and angle matrices
  • borefield_rectangle, borefield_line, borefield_circle
  • borefield_L, borefield_U, borefield_open_rectangle
